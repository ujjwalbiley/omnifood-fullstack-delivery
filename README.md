# 🍽️ Omnifood - Full Stack Food Delivery Web App
> My first full-stack web development project.

## 🌐 Live Demo
[View Live Website](https://ujjwalbiley.github.io/omnifood-fullstack-delivery/)

## 📌 About The Project
Omnifood is my first full-stack web development project.
It is a responsive food delivery web application built using
HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

The project helped me understand how a frontend application
communicates with a backend API and how data can be stored
in a MongoDB database.

## 🚀 Features
- Responsive food delivery website
- Food menu/cards
- User interaction with JavaScript
- Signup/reservation form
- Backend API using Node.js and Express.js
- MongoDB database integration
- REST API routes
- Responsive design for different screen sizes

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- Git & GitHub
